## Run it

```sh

```

`main.ts` (Node 22, standard library only) copies the finished `entry.png` — a 1024×1024 front-page-style summary drawn with PIL (`gen_image.py`) — to `/output/entry.png`. Both runs write identical bytes. No network is used.
